# Personal examples

The user's assignments often use a real example from work or life. A story appears as the user's own experience only when the user gave it, or chose to have it written.

## When an assignment needs an example the user did not give

1. **In the plan**, suggest at least 3 story ideas drawn from the user's profile and memory, each in a line or two: the situation, and the main idea it would show. The user can answer with a real example, with "idea X happened" plus the real details, or with "invent."
2. **If the plan was skipped**, write the paragraph so it reads well without the example. Add `[ADD YOUR EXAMPLE: what kind of example fits here]` to that paragraph's evidence block, with where it goes (for example, "After S3"), and give the story ideas under "Before you submit."

## When the user says "invent"

Write the story in first person as the user's experience, without asking again. Draw on the user's profile and memory. If neither is available, use the user's background: a software team leader at a SaaS company that builds a dealership management system. Label the story's sentences `[INVENTED - NEED TO VERIFY]` in the evidence block, never in the text, and list the story under "Before you submit."

Write in the hypothetical style ("Imagine a team that...") only when the user asks for it.
