# Default top-band standard

Use this only when the user has no rubric. Say in the output that this default standard was used instead of the real rubric, so the user knows what the assignment was measured against.

Real rubrics vary, so treat this as a floor, not a ceiling. If the user later supplies the real rubric, check the assignment again against it.

| Criterion | Top band |
|---|---|
| Answering the question | Every part of the question is answered directly and in enough depth. Nothing important is left implied. |
| Thesis and structure | The introduction states a clear thesis. Each body paragraph has one main idea and a topic sentence that links back to the thesis. The conclusion sums up the answer and adds nothing new. |
| Critical thinking | The assignment analyzes and evaluates. It compares ideas or sources, weighs strengths and limits, names a specific condition where an idea fails, and gives a reasoned position. It does not only summarize. |
| Use of sources | Each main claim rests on evidence with a citation. At least two sources are used as evidence for the writer's own claims, and at least once the sources are put in relation to each other. Concepts, authors, and studies are named specifically, and key terms follow the course's definitions. |
| Application | A concept is applied to a specific real case, and the outcome or the lesson is stated. |
| Writing quality | Clear and organized, in a plain academic tone. Correct grammar and spelling. One idea per sentence, one topic per paragraph. |
| APA 7 | In-text citations, the References list, and the headings are correctly formatted. Citations and References match both ways. Citations carry page numbers where the source has them, and direct quotes always do. |
| Requirements | The word count, the minimum number of sources, the title, and every formatting rule in the instructions are met. |
