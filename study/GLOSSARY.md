# Study

University coursework done in the user's own voice: discussion forum posts, written assignments, and coding assignments.

## Language

### The forum

**Post**:
Any message in a discussion forum.

**Initial post**:
A student's answer to the discussion question.
_Avoid_: main post, original post

**Reply**:
A post that responds to another post.
_Avoid_: response, comment

**Thread**:
An initial post and all the replies under it.

**Classmate**:
Another student in the same course forum.
_Avoid_: peer, fellow student

**Grader**:
Whoever grades a post: usually the instructor, or the user during an assessment.
_Avoid_: marker, assessor

### Sources

**Course material**:
A reading, lecture note, slide set, or video that the course assigns or names for the task.
_Avoid_: topic knowledge, course resource, readings

**Outside source**:
Any source that is not course material.
_Avoid_: external source, web source

**Resource check**:
The gate before any work starts: every file, link, and pasted text the user gives, and every course material the task names, must open and read in full.

**Evidence block**:
The notes under each paragraph of a draft that give, for each sentence, its source, its location, and an exact quote. The user deletes them before submitting.

**Label**:
A marker in an evidence block that says where a sentence comes from, such as the user's own experience or opinion. It needs no action.
_Avoid_: tag

**Flag**:
A marker in an evidence block for something the user must fix or check before submitting.
_Avoid_: tag, note

### Rubrics

**Band**:
One level of a rubric criterion, such as "Exemplary" or "Developing".
_Avoid_: level, column, tier

**Top band**:
The highest band of a rubric criterion.

### The work

**Plan**:
The one checkpoint before drafting, where the user approves what the draft will say and which sources it will cite.
_Avoid_: source plan, source list, outline

**Review**:
A check of the user's own post before it is submitted, giving targeted edits rather than a rewrite.
_Avoid_: proofread, critique

**Assessment**:
A grade or rating of a classmate's initial post against the discussion rubric, with a short, kind feedback comment. It goes to the course's grading form, never into a reply.
_Avoid_: peer review, evaluation

**Move**:
One of the five things a reply does with the post it answers: extend, question, connect, apply, or synthesize.
