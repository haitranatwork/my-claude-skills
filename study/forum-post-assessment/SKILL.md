# Assess a classmate's initial post

Grade one classmate's **initial post** fairly against the discussion rubric, and write a short, kind feedback comment the user can paste into the course's grading form. The grade and the comment go only into that form. A forum reply to the same classmate is a separate task (`forum-post-reply`), and a reply never grades.

Other forum tasks have their own skills: `forum-post-create` writes the user's initial post, and `forum-post-review` reviews the user's own draft. If the user pastes a classmate's post without saying whether to grade it or reply to it, ask which one before starting.

## Inputs

**One classmate post per prompt.** If a prompt holds more than one, ask which one to assess now; the user sends the next one in its own prompt.

The user fills in `assets/input-template.md`, or pastes the same parts.
- **Required:** the classmate's full initial post with its References, the discussion question, the rubric, and the course material.
- **Optional:** the course's assessment instructions and scale (for example, "rate from 1 to 10"). With no scale, grade in rubric bands.

## Steps

1. **Resource check.** Read `references/resource-check.md` and run it. Also check every course material the classmate's post cites. The classmate's outside sources are not part of the gate; open them in step 4. For a later classmate in the same chat, check only the new post and any new course material it cites.
2. **Read the standards.** Read `references/rubric.md`, `references/strong-post.md`, `references/apa7.md`, and `references/sources.md`. Decode the rubric: the top band and the delta for each criterion.
3. **Grade.** For each criterion, find the band the post earns. Quote the classmate's own words that show it, or, for a criterion the post misses, say what is missing. Then give the score on the course's scale and show how you reached it. With no scale, give the band for each criterion.
4. **Check accuracy.** For each claim that cites course material, check that the cited part says it. Check the citation format in the text and in References (see `apa7.md`). Open each outside link the post cites, and note any that do not open, without assuming the classmate is wrong. Report each problem with the classmate's words.
5. **Write the feedback comment.** Read `references/language.md` and `references/voice-sample.md`, and write in the user's voice: 60 to 120 words, unless the form sets a limit. Name one specific strength, then one or two specific things to improve, each tied to a rubric criterion, and close kindly. Keep the score out of the comment.
6. **Deliver** as described below.

## Fairness

- Grade only against the rubric and the instructions. A view that differs from the user's, or from yours, loses nothing.
- English level counts only where the rubric grades writing, and then for clarity, not style.
- A post that reaches the top band gets top marks, and its comment invents no weakness.
- Every band rests on the classmate's quoted words or a named gap, never on an overall impression.

## Deliverable

In the chat, in this order:
1. **Score:** on the course's scale, with how it was reached; or, with no scale, the band for each criterion.
2. **Rubric table:** criterion | band | one-line reason | the classmate's words.
3. **Accuracy check:** claims the cited course material does not support, citation format problems, and outside links that did not open. Write "None found" when there are none.
4. **Feedback comment:** in its own block, ready to paste into the form.
