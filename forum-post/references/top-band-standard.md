# Default Top-Band Standard

Use this only when the user has no rubric to paste. Say in the deliverable that this default standard was used instead of the real rubric, so the user knows what the draft was measured against.

Real rubrics vary. Treat this as a floor, not a ceiling. If the user later supplies the real rubric, re-check the draft against it.

| Criterion | Top band |
|---|---|
| Answering the prompt | Every part of the question is answered directly and in enough depth. Nothing important is left implied. |
| Critical thinking | The post analyzes and evaluates. It applies a concept to a specific case, names a limit or condition, or weighs two views. It does not only summarize. |
| Use of course material | At least two sources are used as evidence for the writer's own claims, and at least once the sources are put in relation to each other. Concepts, authors, and studies are named specifically. |
| Original contribution | The post adds at least one idea, example, or angle that a classmate who did the readings would not already have. |
| Engagement | The post ends with a genuine open question that gives classmates a real opening to reply. |
| Writing quality | Clear and organized. Correct grammar and spelling. One idea per sentence, one topic per paragraph. |
| APA 7 | In-text citations and the References list are correctly formatted and match each other. Direct quotes carry page numbers. |
| Requirements | Word count, citation minimum, title, and any formatting rule are all met. |
